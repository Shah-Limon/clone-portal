# Clone Portal — FinanceFeeds & FxDailyInfo Design Studies

Pixel-faithful design clones of two trading-news sites, built with **Tailwind CSS + custom CSS**. No build step, no framework — just static HTML.

## Pages

| Clone | Description |
|---|---|
| [`financefeeds.html`](./financefeeds.html) | Magazine-style trading news — Roboto Slab serif headlines, red accent on navy, breaking-news ticker, live market data |
| [`fxdailyinfo.html`](./fxdailyinfo.html) | Forex bonus portal — Inter + Playfair Display, green-on-navy, award marquee, tabbed bonus categories |

## Tech

- **Tailwind CSS** via CDN with custom theme tokens
- **Google Fonts** (Inter, Playfair Display, Roboto, Roboto Slab)
- **Zero JS dependencies** (vanilla for tabs, countdown, marquee)
- **Responsive** breakpoints at 1024 / 768 / 480

## Run Locally

```bash
python3 -m http.server 8080
# open http://localhost:8080
```
