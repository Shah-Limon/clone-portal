Build Notes

📐 Layout

Tailwind utility classes for grid + spacing. Custom CSS handles marquees, sticky header, ticker scroll, tab transitions, and reduced-motion fallbacks.

🎨 Design Tokens

Each clone has its own palette and type system — FxDailyInfo uses Inter + Playfair Display with green-on-navy. FinanceFeeds uses Roboto Slab serif headlines with red accents.

📱 Responsive

Breakpoints at 1024 / 768 / 480. Desktop nav collapses to hamburger on mobile; 3-col grids collapse to 2 or 1; sticky sidebars become static.
